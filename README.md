# AE 內建特效圖鑑

After Effects 內建效果的中英對照參考，共 290 個效果、22 個分類（依 Adobe 官方效果清單整理），每個效果都有網頁即時運算的動態預覽。

**線上瀏覽：** https://capsuleuwu.github.io/AE-Effects-Guide/

## 功能

- **中英對照**：英文名稱、繁體中文名稱與用途說明，英文名稱可一鍵複製到「效果和預設集」面板搜尋。
- **動態預覽**：滑鼠移到卡片上即播放；點擊卡片可放大，並用滑桿手動調整強度或轉場進度。
- **分類與搜尋**：依 AE 效果選單分類，可用中文或英文搜尋。
- **顯示比例**：大螢幕可切換「放大顯示」（150%）。
- **收藏**：把常用效果加入「我的收藏」（儲存在瀏覽器的 localStorage）。
- **製作提示**：需要先新增純色圖層（Solid）或空物件（Null）的效果會另外標示說明。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，單一檔案、不需要安裝任何東西。

## 說明

預覽畫面皆為網頁即時運算的示意動畫，用來表達特效的呈現方式，與 AE 實際算繪結果會有差異。中文名稱以繁體中文版 AE 的常見譯名為主，不同版本的翻譯可能略有出入。
